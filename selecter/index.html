GeoJSON Viewer and Selecter

Explore, filter, and export geographic data from files or directly from the map.

📄
File mode

Load a GeoJSON file

Browse properties, filter by value, highlight features, and save selections.

  • Click a property value to highlight
  • Click again to filter or exclude
  • Label features by properties
  • Save selected or visible features
  • Drag in multiple files to combine layers

Coordinates are automatically truncated to 6 decimal places (~11cm precision) to reduce file size. Files in other coordinate systems (e.g. California Albers EPSG:3310) are automatically reprojected to WGS84 on load.

⚠ Files over 100MB may cause browser memory issues depending on their complexity.

🗺
Map mode

Browse map tiles

Click roads, paths, and transit lines directly on the map to select them.

  • Click to select a road segment
  • Click again to deselect
  • ⇧ Shift+click to select segments of lines and sub-segments from large MultiLineString blobs
  • Add selections to a GeoJSON layer
  • Save selected features
